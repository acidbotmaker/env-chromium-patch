Capture a fingerprint profile

Reads this machine's real values and writes them out as a profile for env-chromium-patch.

Run this in stock Chrome on the machine you want to imitate, not in the patched build — a patched build would just echo back whatever it was already configured with.
  1. Click Grant camera + microphone so device labels are readable. Without permission the labels come back empty and the media section will be left as a placeholder.
  2. Click Capture.
  3. Save the output as profiles/<name>.env in the patch repo.
